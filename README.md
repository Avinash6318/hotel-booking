# 🏨 Hotel Booking Platform

A full-stack hotel booking application built with the MERN stack. The platform allows users to explore hotels, view rooms, make bookings, and securely complete payments.

## 🚀 Live Demo

[Live Demo](https://booknow-two.vercel.app)

## 📂 Repository

[GitHub Repository](https://github.com/Avinash6318/hotel-booking)

---

## ✨ Features

- 🔐 User authentication with Clerk
- 🏨 Browse available hotels and rooms
- 🔎 View hotel and room details
- 📅 Room booking functionality
- 💳 Secure online payments using Stripe
- 🖼️ Image management using Cloudinary
- 📱 Responsive user interface
- 🔒 Protected routes and authenticated actions
- ⚡ RESTful backend APIs
- 🌐 Production deployment using Vercel
- 🔄 Frontend-backend API integration
- 🗄️ MongoDB database for persistent data storage
